# Mini Message Board

A simple Express.js and EJS application that lets users view and post messages.

## Features
- View all messages
- Add a new message via a form
- View individual message details
- Server-side rendering with EJS

## Tech Stack
- Node.js
- Express.js
- EJS

## Updates

- Added PostgreSQL database persistence using `pg`
- Added server-side validation with Express Validator
- Added database setup
- Connected app to Render PostgreSQL
